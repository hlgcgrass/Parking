**架构说明**

```
小程序 wx.cloud.callFunction          云函数 parking
      │                                    │
      ├── 只读数据（ places/nearby/  ─────→├─ data.json 内存查询（毫秒级，不耗数据库读配额）
      │    search/detail/hot 等）          │
      │                                    │
      └── 互动数据（login/收藏/点赞）─────→├─ 云数据库 p_users / p_favorites / p_likes
                                           │
                             身份 = getWXContext().OPENID（不接受前端传 userId）
```

**安全提升**：旧方案把密钥写在小程序里（可被反编译提取）；云开发下所有请求都带微信登录态，云函数直接读 OPENID，前端传什么都不认——**刷点赞、伪造身份、拖库都失效了**。

## 三、只剩一步：上传部署云函数

> 这一步必须做，否则小程序调不到云函数，`parking` 不存在 → 页面报错「云函数 parking 未部署」。

### 方式 A：命令行一键部署（推荐，可重复执行）

1. 到 **微信公众平台** → 开发与服务 → 开发管理 → **开发设置** → **代码上传密钥** → 下载，得到 `private.wx74cf1625553c595b.key`
2. 同页面的 **IP 白名单**：填入你的公网 IP，或临时关闭限制（否则会报白名单错误）
3. 把 `.key` 文件放进 `server/keys/` 目录（没有就新建）
4. **双击 `server/deploy-cloud.bat`**，等提示「云函数部署成功」

以后每次改 `cloudfunctions/parking/` 里的代码，重新双击即可。

### 方式 B：IDE 里手动上传（不需要密钥，最稳）

左侧资源管理器（或云开发资源管理器）中找到 `cloudfunctions/parking`
→ 右键 **「上传并部署：云端安装依赖」** → 等右下角提示成功。

> 第一次较慢，因为要在云端安装 `wx-server-sdk`。
