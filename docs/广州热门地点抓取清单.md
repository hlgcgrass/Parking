# 广州热门地点停车攻略抓取清单

> 版本：2026-09-10
>
> 用途：作为广州停车攻略抓取任务的地点输入清单。地点图片和攻略抓取均应优先处理 P0，再处理 P1。地点名称以用户在小红书、地图和搜索引擎中最常用的主搜索词为准，入口、院区、展区等细分信息放到攻略内容中。

## 一、抓取优先级

- **P0：现有核心地点**：当前广州停车攻略数据中已有的景点/公共文化和医院 35 个，加上北京路、体育西路等 10 个高频核心街区/片区。
- **P1：重点补充**：广州知名度高、停车需求明显，适合第一批扩充。
- **P2：后续扩展**：区域性热门地点、展会/节假日热点和长尾地点，待 P0/P1 稳定后再抓取。

### 名称清洗说明

- 地点主名称只保留用户最可能直接搜索的自然地名，例如使用“白云山”“广州塔”“沙面”，不把南门、西门、俗称、院区或展区塞进主名称。
- “广州塔（小蛮腰）”统一为“广州塔”；“沙面岛”统一为“沙面”；“南越王墓博物馆”统一为“南越王博物院”；“永庆坊/荔枝湾”统一为“永庆坊”。荔枝湾涌如需抓取，后续单独作为地点增加。
- “长隆”是用户常用搜索词，但攻略抓取时要继续拆分长隆欢乐世界、长隆野生动物世界、长隆水上乐园等具体目的地和停车入口。
- 医院和高校主名称使用用户常用简称或主体名称。
- 商业类地点只保留用户会直接搜索、且停车需求明显的核心街区、片区和标志性商业地标，不再单独维护普通商场清单。

## 四、建议的抓取关键词

每个地点只使用一个抓取关键词：

```text
广州 + 地点名 + 停车攻略
```

## 五、清单依据

- 广州市文化广电旅游局的 A 级旅游景区名录，用于景点初筛。
- 广州市商务部门公布的重点商圈和高质量商圈规划，用于核心街区和片区初筛。
- 广州市卫生健康部门的医院信息，用于医院名称核验。
- 广州综合交通枢纽规划，用于机场、铁路站、客运站等交通枢纽初筛。

## 六、执行建议

第一轮按以下顺序执行：

1. P0 的医院、交通拥堵明显的景点和公共文化地点。
2. P0 的其他景点。
3. P1 的医院和交通枢纽。
4. P1 的景点、场馆、高校和政务地点。

同一地点的多个停车场应拆成停车点记录，避免把不同停车场的收费规则混在一起。
