# 停车攻略小程序 · UI 设计规范

> 风格：**A · 晨雾青（Mint Mist）**
> 版本 v1.0 ｜ 2026-09-09
> 本文件是所有页面的唯一视觉依据。新增页面、组件前先读这里，不允许出现文档外的颜色/字号/圆角。

---

## 零、设计主张

**一句话：像一张干净的公园导览图，而不是一张促销传单。**

三条不可违背的原则：

1. **克制优于装饰** —— 不用渐变、不用大面积色块、不用重投影。高级感来自留白、对齐和一致的细节，而不是特效。
2. **信息优先于视觉** —— 用户是来查价格和位置的，任何妨碍快速扫读的装饰都删掉。
3. **诚实优先于好看** —— 见第九章「可信任设计」，这是本产品的生命线。

## 一、色彩系统

### 1.1 主色（晨雾青 teal）

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `primary-50` | `#E1F5EE` | 选中标签底、浅色强调区、状态点底 |
| `primary-100` | `#9FE1CB` | 头像占位底、图表辅色 |
| `primary-400` | `#1D9E75` | **主按钮底色**、成功状态、图表主色 |
| `primary-600` | `#0F6E56` | **价格文字**、链接、次按钮文字、图标强调 |
| `primary-800` | `#085041` | 主标题文字（绿黑色，比纯黑柔和） |

> 主按钮用 400 而非 600：深色按钮 + 白字需要足够对比，400 在深底上更通透，不会显得沉闷。

### 1.2 中性色

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `text-1` | `#2C2C2A` | 一级文字：页面大标题、卡片主标题 |
| `text-2` | `#5F5E5A` | 二级文字：正文、副标题、说明 |
| `text-3` | `#888780` | 三级文字：辅助信息、占位符、时间 |
| `text-4` | `#B4B2A9` | 四级文字：禁用态、分隔符 |
| `bg-page` | `#F5F7F6` | 页面底色（极淡青灰，比纯白有呼吸感） |
| `bg-card` | `#FFFFFF` | 卡片、导航栏、弹窗 |
| `bg-fill` | `#F1EFE8` | 未选中标签底、输入框底、代码块底 |
| `line` | `#EDEDED` | 分割线（0.5px） |
| `mask` | `rgba(0,0,0,0.45)` | 弹窗遮罩 |

### 1.3 语义色

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `success` | `#1D9E75` | 车位充足、成功提示 |
| `warning` | `#EF9F27` | 车位紧张、提醒 |
| `danger` | `#E24B4A` | 满位、错误、删除 |
| `saving` | `#BA7517` | 「省钱」相关强调（省了多少钱） |
| `free` | `#FAECE7` 底 + `#993C1D` 字 | 免费/优惠标签 |

### 1.4 使用纪律

- 一个页面内**主色不超过 2 个色阶**（通常 50 做底 + 600 做字），避免花。
- 中性文字只用 text-1 到 text-4，禁止自定义灰。
- 价格统一用 `primary-600`，不用红色——红色会让人联想到促销和涨价，与「帮你省钱」的定位冲突。

## 二、字体

### 2.1 字体族

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
             "Helvetica Neue", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

数字（价格、距离、车位数）用系统默认即可，不引入第三方数字字体。

### 2.2 字号阶梯（单位 rpx，设计稿 750 = 屏幕宽）

| 令牌 | 大小 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| `fs-display` | 40rpx (20px) | 500 | 1.4 | 页面主标题、价格大数字 |
| `fs-title` | 34rpx (17px) | 500 | 1.4 | 卡片标题、导航标题 |
| `fs-subtitle` | 30rpx (15px) | 500 | 1.5 | 小标题、列表主标题 |
| `fs-body` | 28rpx (14px) | 400 | 1.6 | 正文 |
| `fs-caption` | 24rpx (12px) | 400 | 1.5 | 辅助说明、时间、来源标注 |
| `fs-tag` | 22rpx (11px) | 400 | 1.4 | 标签、角标、最小辅助文字 |

### 2.3 字重纪律

**只允许 400（常规）和 500（中粗）两个权重。禁止 600 / bold。**

粗体会让界面显得廉价、促销味重。需要强调时，用**颜色**或**字号**区分，而不是加粗。这是"精致感"和"牛皮癣广告"的分水岭。

### 2.4 文字颜色搭配

- 标题 `text-1` / 正文 `text-2` / 辅助 `text-3` —— 三级足够，不要出现第四种灰在正文里。
- 一行内不要超过两种颜色。
- 占位符统一 `text-3`。

## 三、圆角

| 令牌 | 大小 | 用途 |
| --- | --- | --- |
| `radius-sm` | 8rpx (4px) | 小标签、进度条、状态点背景 |
| `radius-md` | 16rpx (8px) | 标签 chip、小按钮、图片缩略图 |
| `radius-lg` | 24rpx (12px) | 按钮、输入框、搜索框 |
| `radius-xl` | 32rpx (16px) | **卡片**（整个产品最主要的圆角） |
| `radius-full` | 999rpx | 胶囊标签、头像、状态圆点 |

> 卡片统一 16px 圆角，全站一致。不要混用 12/16/20，混用会立刻显得不专业。

---

## 四、间距（4pt 栅格）

| 令牌 | 大小 | 用途 |
| --- | --- | --- |
| `space-xs` | 8rpx (4px) | 图标与文字之间 |
| `space-sm` | 16rpx (8px) | 紧密元素 |
| `space-md` | 24rpx (12px) | 卡片内元素间距 |
| `space-lg` | 32rpx (16px) | **卡片内边距、页面左右边距** |
| `space-xl` | 48rpx (24px) | 区块之间 |
| `space-xxl` | 64rpx (32px) | 大分区之间 |

**硬性规定：**
- 页面左右安全边距 **32rpx（16px）**，所有内容对齐这条线
- 卡片内边距 **32rpx**，不允许 20/24/28 这类随意值
- 卡片之间的间距 **24rpx**（12px）
- 列表项内部元素间距 **8-16rpx**

## 五、按钮

### 5.1 主按钮（Primary）

```
高度 88rpx (44px)    圆角 24rpx (12px)
底色 primary-400 #1D9E75    文字 #FFFFFF fs-subtitle 30rpx/500
无边框、无阴影
按下态：底色变 primary-600 #0F6E56，无缩放动画
禁用态：底色 primary-50，文字 primary-100
```

### 5.2 次按钮（Secondary）

```
高度 88rpx   圆角 24rpx
底色 #FFFFFF   0.5px 边框 primary-400   文字 primary-600
```

### 5.3 文字按钮（Text）

```
无背景无边框，文字 primary-600 fs-body
点击区域最小 88rpx 高（可点击区域不低于 44px）
```

### 5.4 小按钮（Small）

```
高度 64rpx (32px)   圆角 16rpx   左右内边距 24rpx
文字 fs-caption 24rpx
主色版：底色 primary-50，文字 primary-600（不抢主按钮视觉）
```

**纪律：** 一个页面最多一个主按钮。所有按钮高度必须是 88rpx 或 64rpx，不允许 70/80 这类值。

## 六、卡片

```
底色 #FFFFFF
圆角 32rpx (16px)
边框 0.5px solid rgba(0,0,0,0.04)
阴影 0 2rpx 8rpx rgba(16,62,55,0.04)   ← 极淡，带一点点青，不可用纯黑阴影
内边距 32rpx
```

- 卡片内元素间距统一 16rpx 或 24rpx
- 可点击卡片：按下时底色变 `#FAFBFA`，不放缩、不加粗
- 卡片之间不嵌套卡片（信息层级用分割线区分，不用套娃）

## 七、列表项

标准停车场列表项结构：

```
┌────────────────────────────────────┐
│ 车场名称 fs-subtitle text-1    ¥10/h│  ← 价格右对齐 primary-600
│ 类型·车位规模 fs-caption text-3      │
│ ● 车位充足 text-3        步行 320m   │  ← 状态点 + 距离右对齐
└────────────────────────────────────┘
```

- 最小高度 152rpx（76px）
- 分割线：`0.5px #EDEDED`，左边距 32rpx（与内容对齐），右边不留
- 价格数字用 `fs-title`(34rpx) 时突出，用 `fs-subtitle` 时常规，同一列表内必须统一

## 八、组件细节

### 8.1 搜索框

```
高度 80rpx (40px)   圆角 40rpx (全圆)
底色 #F5F7F6   无边框
左图标 32rpx primary-600（放大镜，线性 2px 描边）
占位文字 fs-body text-3
```

### 8.2 标签 chip

```
高度 56rpx (28px)   圆角 16rpx   左右内边距 24rpx
未选中：底色 bg-fill #F1EFE8   文字 text-2
选中：底色 primary-50 #E1F5EE   文字 primary-600
无边框
```

分类切换用 chip 组，横向间距 16rpx，可横向滚动。

### 8.3 状态点（车位状态）

```
圆点 12rpx 直径 + 文字 fs-caption
充足 success #1D9E75 ／ 紧张 warning #EF9F27 ／ 满位 danger #E24B4A ／ 未知 text-4 #B4B2A9
```

### 8.4 价格展示

```
主价格：fs-display 40rpx/500 primary-600
单位：fs-caption 24rpx text-3，紧贴数字右侧，不换行
原价（划线）：fs-caption text-4 + line-through
省钱提示：saving #BA7517
```

### 8.5 图标

- 统一**线性图标**，描边 2px，圆头端点，圆角连接
- 尺寸档位：32rpx（内联）／ 40rpx（列表）／ 48rpx（功能入口）
- 颜色跟随文字色，不单独设色
- 全站同一套图标，禁止混用实心/线性

### 8.6 导航栏

```
底色 #FFFFFF（非透明）
标题 fs-title 17px/500 text-1 居中
返回箭头：线性箭头，点击区域 88rpx × 88rpx
底部 0.5px 分割线 #EDEDED
```

## 九、可信任设计 ★ 本产品生命线

用户选择相信我们的价格数据，才不会再去翻小红书。以下为**强制条款**：

### 9.1 数据必须标注来源与时间

每个停车场详情页底部固定显示：

```
数据更新于 2026-09 · 来源：官方价目表 · 仅供参考
```

来源按置信度显示不同措辞：
| 置信度 | 显示文案 |
| --- | --- |
| high | 来源：官方价目表 |
| medium | 来源：公开信息整理 |
| low | 信息未核实，以现场为准 |

### 9.2 绝不编造"实时空位"

**没有接实时数据接口，就不允许显示"剩余车位 23 个"这类精确数字。**

替代方案：只显示**车位规模描述**
- total_spots ≥ 500 → 「大型车场」
- 200-499 → 「中型车场」
- < 200 → 「小型车场」
- 未知 → 不显示该字段

车位紧张度只在有明确依据时显示为文字描述（如「工作日 10 点后基本满位」），不用假的百分比。

### 9.3 低置信数据必须"示弱"

confidence = low 的停车场：
- 卡片右上角显示浅色角标「待核实」
- 价格数字后加 `~` 前缀（如 `~¥10/h`）
- 详情页顶部显示提示条：「该信息未经实地核实，欢迎拍照补充」

**宁可显得数据少，也不能显得数据假。**

### 9.4 空状态要诚实

搜索无结果时：
```
[线性插画：空车位]
没找到「XXX」的停车攻略
你可以点击下方按钮补充这个地点
[+ 补充这个地点]
```
不推荐无关结果充数，不显示"猜你喜欢"来掩盖数据缺失。

### 9.5 不做伪装成内容的广告

任何商业推广内容必须有明确「推广」标识，样式上与真实攻略有明显区分（灰底 + 角标），不得模仿卡片样式。

## 十、动效

| 场景 | 时长 | 效果 |
| --- | --- | --- |
| 页面切换 | 300ms | 系统默认右进右出 |
| 按钮按下 | 即时 | 底色加深，无缩放 |
| 卡片点击 | 即时 | 底色变 #FAFBFA |
| 加载 | — | **骨架屏**，不用 loading 转圈 |
| 下拉刷新 | — | 系统默认 |
| Toast | 1500ms | 黑底白字圆角，无图标 |

**禁止：** 弹跳动画、缩放动画、旋转加载、粒子效果、渐变流光。

## 十一、页面结构模板

### 11.1 首页

```
定位栏（城市 + 切换）          ← 高度 88rpx，primary-50 底
搜索框                          ← 80rpx，页面顶部固定
分类 chip 组                    ← 景点 / 商圈 / 医院 / 附近
热门目的地卡片列表              ← 按 heat 排序，卡片间距 24rpx
```

### 11.2 详情页

```
地点头图/标题栏（地点名 + 分类 + 地址）
区域攻略卡（area_tips）         ← primary-50 底，重点内容
停车场列表（按推荐排序）
  每项：名称 / 价格 / 车位规模 / 步行距离 / 详情箭头
停车费计算器                    ← 输入时长算总价
数据来源标注                    ← 见 9.1
底部操作：导航 / 纠错补充
```
