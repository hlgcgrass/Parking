# 停车攻略整理批次（腾讯定位复核）

本批正式可入库地点：16 个；待补充：4 个。

## 广州图书馆

停车场：广州图书馆停车场
收费：5元/小时（前3小时）；其余时段收费以现场公示为准。
攻略正文：停车后从广州图书馆东门或西门进入；机械车位对车宽有限制，车宽接近1.95米时应先确认是否能安排普通车位。
停车场定位：广州图书馆地下停车场-入口（113.326674, 23.116427）

停车场：花城汇P13区停车场
收费：现场收费约7.5元/小时；预约价格约6.8元/小时且无阶梯收费，规则可能随活动调整。
攻略正文：P13靠近广州塔和海心沙方向，P8、P11、P13均可通过电梯到花城广场地面；步行到海心沙约5至10分钟，预约后按当日规则结算。
停车场定位：花城汇P13地下停车场-入口（113.324959, 23.114544）

## 海心沙

停车场：海心沙亚运公园停车场
收费：5元/小时，24小时封顶25元。
攻略正文：停车后步行到广州塔约8至10分钟；车位相对不易满，场内有充电桩。活动日仍应预留入场时间。
停车场定位：海心沙亚运公园停车场（113.324491, 23.113335）

## 海珠湖

停车场：海珠湖公园停车场
收费：约2.5元/30分钟；具体收费以入口公示为准。
攻略正文：北广场/北门方向可直接进入公园停车场；周末车位较紧张，建议早点到或改乘地铁大塘站。
停车场定位：海珠湖公园北广场停车场（113.326147, 23.077259）

停车场：坚真花园停车场
收费：30分钟内免费，24小时封顶15元。
攻略正文：距离海珠湖约0.77公里，步行约8至10分钟；可作为公园停车位不足时的备选。
停车场定位：坚真花园内部地面停车场-入口（113.326124, 23.082328）

攻略正文：导航沙湾古镇西门，步行进入古镇；周末车位不多，入口可能排队，建议尽量提前到达。
停车场定位：沙湾古镇西门游客服务点地上停车场-入口（113.330738, 22.904747）

停车场：沙湾古镇南停车场
收费：约5元/小时；另有10元/天的收费口径，收费存在差异，现场以当日公示为准。
攻略正文：南门方向停车后步行进入古镇；适合长时间停留，但应在入场时确认按小时还是按天计费。
停车场定位：沙湾古镇南停车场-出入口（113.337117, 22.901158）
