## 滑块仍"滑两次" → 收敛为社区标准方案（12:05）
- **二次滑动根因**：源实例点击时被 setData 到目标位后**残留**；切回该页时 onShow sync 发现 selected≠当前页 → 又带动画滑一次 → "滑两次"
- **终版方案（社区标准收敛写法）**：① 全局唯一位置 g.pos；② 点击时仅当前可见实例播放一次动画，滑完(300ms)才 switchTab（g.timer 防连点打断）；③ **静默归位 place(i)**：置 `noAnim`（组件根 class → wxss `.no-anim .tab-slider{transition:none}`）→ setData 直接定位 → 60ms 后恢复动画；attached（实例新建）与页面 onShow sync 一律走 place → 任何目标/残留实例**只定位不滑动**，杜绝二次动画
- 效果：一次点击=当前页面滑块滑一次→切页→目标页滑块已在位（不再有第二次），方向、次数全部确定
